# 扫描合集由配置目录决定，过期记录按目录分别清理

[ADR 0001](0001-增量扫描复用已有媒体处理结果.md) 已经写明「以当前保存的全部目录形成扫描合集」，以及「数据库中不属于扫描合集的视频记录直接删除，不保留不可用占位」。但代码没有落实这条规则：决定清理范围的依据是「本次扫描实际找到了哪些文件」，而本次扫描覆盖哪些目录由调用方给出。推断因此是：不变式只靠调用方自觉，而不由代码保证。后端有一个只传单个目录的扫描命令，一旦被调用，它的差集清理会把其他所有目录的记录删掉；前端恰好没有调用方，这是巧合，不是保证。

同时 0001 的一条规则需要修订。它写「目录无法完整读取时保留原库，不执行差集清理」。这条把单点故障放大成全库停摆：一条目录读不到，其他目录里确实被删掉的文件也不会被清理。本次改为只跳过出问题的目录。

## 扫描范围由仓储读配置决定，不由调用方指定

判断过期需要「扫描合集」这个全集，而全集的来源只有一个：当前保存的目录。把它放在命令层校验可以让调用方无法传偏，但仓储仍可被内部调用方绕过；放在仓储里才有唯一执行点。因此扫描范围改由仓储读取配置目录得出，命令不再接收目录列表，前端那处传参一并退场。

只传单个目录的扫描命令随之失去意义并删除。它的参数在新规则下必然撒谎——扫描范围已不由它决定——留着会诱导下一个人使用它，而它正是上面那个隐患的来源。

配置目录为空时，扫描会清空全部记录：此时没有任何记录属于扫描合集。界面上「当前没有配置视频目录，是否继续？」的确认保持为兜底。

## 清理按目录分别判定

判据从「一条全局差集」改为按目录分别判定，因为只有这样才能区分两种「本次没找到」：

- **该目录成功扫描过**，其中某个文件已不在扫描结果里 —— 该记录过期，清除；
- **该目录本次读不到** —— 整个跳过，其记录不因这次扫描成为过期记录。

此外，记录路径不在任何配置目录下的一律清除。这一条顺带满足「移除保存目录后其记录应当清理」：移除后它不在配置全集里，下一次扫描就会清掉，不需要在移除时写级联删除。

## 读不到的目录与读不出的文件只跳过并计数

一条目录读不到，或遍历中某个文件打不开、元数据取不到、MD5 算不出来，都不再中断整次扫描：跳过它、计入失败、其余照常。理由是单点故障不该拖住全库——一台移动硬盘没插上，不该让别的目录里被删掉的文件也清理不掉。

代价是问题的呈现方式变了：从「整次扫描报错」变成「静默跳过 + 一条很快消失的计数」。完成统计新增「N 个目录当前不可访问」，与「新增／更新／移除」并列，因为它与那三项是同一层级的事实——这次扫描对配置全集做了什么——而「媒体处理失败」指向的是媒体解码，混在一起会把原因指错地方。这一项**不**让通知转常驻：它仍按 3 秒自动关闭。由此产生一处已知的信息可见性损失：通知关闭后，界面上没有任何地方再显示「有目录没被扫描」，用户可能不知道这次结果不完整。接受。

## 空目录按「其中的视频都已消失」处理

目录存在、能读、但一个文件都没有时，其记录按过期清除。这与「用户把某个目录的视频删光了」在代码看来完全一样，没有任何信号能区分；而后者是正常情况，若不清理则记录永久残留。代价是卷挂载异常（网盘掉线后挂载点变成空目录）时会静默清空该目录的记录，其文件下次扫描能重新扫回来，但收藏与播放历史丢失。这一损失与 0001 已接受的「直接删除过期记录会同时丢失收藏和播放历史」是同一类。

## 移除保存目录不立即清除记录，确认语保持原样

移除保存目录只解除配置，不触发扫描，其记录留到下一次扫描时按上面的规则清除。好处是误删可在下一次扫描前挽回。代价是一处**已知且刻意保留**的不符：移除确认气泡写的是「移除“{路径}”的索引？」，而索引并未立即移除，那些视频会继续出现在视频库与目录筛选里，直到用户手动重新扫描（扫描是手动的，可能长期如此）。

这处不符是决策，不是疏漏。记录在此是为了让后人知道它被看见过。若将来要消除它，可选的路径是改确认语如实描述，或在移除后补一条通知说明记录将在下次扫描时移除；两条都改变了上述取舍，需要重新决策，不要顺手「修正」。

## 取舍与影响

- **「不可用」这套机制一并移除。** `videos.available` 列、`VideoFile.available`、前端属性，以及卡片与菜单的播放禁用、详情抽屉的「文件不可用」提示和对应文案键。按上面的规则，没有任何写入者会让记录处于「存在但不可用」的状态，这些读者都已无来源。代价是文件缺失或目录失联时界面不做任何标记，点播放才弹本地化错误。
- **过期记录的定义已在 [`CONTEXT.md`](../../CONTEXT.md) 更新。** 原定义写「当前保存的全部视频目录中发现的视频文件的并集」，按「发现的」算会推出「读不到的目录其记录即过期」的错误结论；现改为按配置定义，把跳过目录的例外写进**过期视频记录**的定义里。
- **实现面。** 按目录清理要求仓储知道哪些目录本次成功扫描、哪些被跳过，因此扫描状态需要按目录汇报结果，差集清理不能再是一条全局语句。
- **既有测试需要改写。** 锁住「路径不存在即中断整次扫描」的用例、锁住「删除文件标记不可用」的用例，都按新行为重写。

## 实施状态

规则已确认，尚未实现。分两票落地：机械移除「不可用」机制的一票不改行为，可以先落地；扫描合集来源、按目录清理、跳过语义、新增计数与删除单目录命令属行为改动，另开一票。落地方案以本 ADR 与 [`CONTEXT.md`](../../CONTEXT.md) 为准。
