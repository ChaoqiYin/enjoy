# 「上次播放」标记记在会话里，浮在缩略图角上

播放由系统默认播放器承接，应用看不见播放中与播放完（开发基线第 11 节），能标记的只有「上一次发起的打开是哪一个」。这一条补的是那个标记：以哪种口径判定「上一次」、长成什么样、画在哪一层。三条候选路都被否决过，下文各记一次。

## 为何记在会话里，而不是取播放历史里最新的那条

数据侧本来就有 `last_played_at`（`record_play` 在打开请求提交成功后写入），全局取最大值就是一个天然的「上一次播放」。那条路不用新增任何状态，重启后也还在，与「最近播放」页的排序同源。

否决它的理由是**口径不同**：索引里那份历史是跨次运行的记录，用于「最近播放」页；而这枚标记回答的是「我刚才播的是哪个」。取历史最大值意味着三个月前播过的视频在每次启动时都被标上，用户没有做过任何动作，标记却已经在说「上次播放」。两条口径各自成立，不必合并。

选定会话状态：应用级 `useLibrary` 持有一个 `lastPlayedId`，点播放且打开请求成功后写入，应用退出即清空。代价明确接受——重启后标记消失，而那次播放仍在「最近播放」页里。

写入的时机是 `await` 之后而不是点击当下。打开失败不增加次数、不记时间（开发基线第 11 节），标记跟同一条规则走：失败的打开只产生一条错误通知，卡片保持原样。

## 为何是浮在缩略图角上的独立元素

否决过三条，都落在同一处：**卡片高度**。虚拟网格按估算的行高分配位置再实测回填（`useVirtualCollection`），ADR 0008 那套悬停几何也挂在卡片尺寸上——多出一行就会让这些数值一起漂。

- **改卡片描边**：悬停的中性描边与键盘聚焦的描边已经占了 `outline`，再加一个写入方就是 ADR 0007 记录的缺陷。
- **改卡片底色**：卡片底色是悬停阴影所在的那层表面，叠色之后阴影与底色的关系要重新量；而且一块被染色的卡片读起来像「选中」，而它不是选中。
- **加进正文的信息行**：窄卡片那一行本来就会换行，多一枚标签可能把它挤成两行，卡片高度随之变化。
- **选定**：一个绝对定位的元素浮在缩略图左上角，脱离文档流。

脱离文档流这条是实测过的，不是推论：在这张卡上点播放之后，**同屏每一张卡片的盒、每一行的盒与滚动高度都逐位不变**。标记落在距卡片盒 8 像素处，其中 1 像素是卡片自己的边框，其余 7 像素即 `top-2 start-2` 在 `html { font-size: 14px }` 下的取值；相对缩略图则是距其左上角 7 像素。悬停时卡片放大到 1.02，这一偏移随之变成 8.16 像素，标记跟着卡片一起动。

## 为何取 `badge-neutral`，以及一条被实测推翻的推断

**先写下、后被推翻的那条**：初稿的理由是「`neutral` 与 `neutral-content` 两半都随主题翻转，所以压在任意缩略图上都读得清」。它由令牌名推出来，实测不成立——构建产物上 `--color-neutral` 在亮暗两个主题下都是 `oklch(14% .005 285.823)`，而 `base-100` 一个是纯白、另一个是 `oklch(25.33% …)`，翻转的只有后者。

**实测之后成立的说法**：这枚标记不随主题翻转，亮暗两主题下都是同一枚近黑底、近白字的标签，同一张缩略图上看到的完全一样；它的文字与自己的底色是 15.68:1，压在任意图片上都读得清。代价落在标记自身的**边框**上而不是文字上：压到很暗的缩略图上时那块底色不再看得出是一个盒子，文字仍然可读。这也是不把它做成半透明或染色的原因——底色一旦不透明，文字就永远落在它上面，而不是落在照片上。

## 验证与未做的部分

- **jsdom 能验的**：只有那一个 id 的卡片长出标记、其余卡片没有；标记是 `absolute` 且不在 `.card-body` 内。jsdom 不做布局，落点与遮挡在测试里没有可断言的落点。
- **真实浏览器里量过的**（构建产物渲染、Tauri IPC 用桩、真实鼠标点击卡片上的播放按钮）：只有被点的那张卡长出标记；点击前后每张卡片、每一行、滚动高度逐位相同；标记距卡片左上 8 像素、字号 10.5px、圆角 7px；标记中心的像素在点击前后变过，即画在图片之上而不是被图片盖住；悬停时标记仍在且相对卡片的位置随之缩放。截图（浏览器渲染构建产物所得，**不是桌面端窗口截图**）：[上次播放标记亮色主题](../验收截图/上次播放标记亮色主题.png)、[上次播放标记暗色主题](../验收截图/上次播放标记暗色主题.png)。
- **桌面端走查尚未进行**：真实窗口里的观感、标记压在不同真实缩略图上的可读性、以及 HiDPI 下的表现都没有走过一遍。测试与上述测量只覆盖行为与几何，不代表已经在真实界面看过了。
