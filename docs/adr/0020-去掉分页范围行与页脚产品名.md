# 去掉分页的范围行与页脚的产品名

两处界面文字被删掉，各自都因为在一个已经说过的屏幕上再说一次同一条事实。

**分页底部的「显示第 1 至 24 个结果 • 共 48 项本地记录」。** 这段话出自原型 `_8`（`prototype-drawing/_8/code.html` 底部画着「显示第 1 至 6 个结果」），实现时又补上了总数。它说的事实屏幕上有两处已经说了：列表上方的标题写着本库共多少条，底下那排页码写着能翻到哪里。三处同一件事里，这一处是唯一没有读者的一处——它既不是给翻页用的（翻页靠按钮），也不是给「这库有多大」用的（标题更近、更大）。`shared/ui/pagination.tsx` 里那句注释本来就写着「条数已经在工具栏上了」，只是当时只拿它论证「单页时不画」，没往下推到范围行本身。

**页脚起始边的产品名「本地视频统一启动器」／`Enjoy Unified Media Launcher`。** 窗口的标题栏与页头都写着这是什么，页脚是第三处。去掉之后页脚只剩右簇的端口与编码加速——两条都是只有运行期才知道的事实，正是这一栏该放的东西。

## 取舍

**删掉范围行，而不是把它挪个位置或改成更短的写法。** 它承载的信息（区间与总数）没有一处是屏幕上缺的，换位置只是换个地方重复；缩短（例如只留「共 48 条」）则与上方标题逐字重复。

**删掉产品名，而不是把它换成别的标识。** 页脚不是品牌位；这一栏存在的理由是它报告平台事实。

**两处都不留占位。** 分页底部那条分隔线保留（`border-t`），页码组改为贴右排布（原先是「范围在左、页码在右」的两端对齐，左边空了之后就只剩对齐方向本身）。页脚的横线同理保留。

## 它推翻了什么

- **原型 `_8` 画的那行范围**不再实现。原型稿是历史产物，不重画；本条记下分歧。
- **`paginationSummary` 与 `footerProduct` 两个词条**从 `shared/locales/en/common.json` 与 `zh-CN/common.json` 一并删除——没有调用方的词条会被 `check-translations.mjs` 报出来。

## 后果

- `shared/ui/pagination.tsx` 不再需要 `from` / `to` 两个值，`pageSize` 只剩算页数一个用途。
- 三条既有用例断言的是那句范围文案（`shared/ui/pagination.test.tsx`、`features/library/Pagination.test.tsx`、`features/library/VideoPageContent.test.tsx`、`features/share/SharePage.test.tsx`），改为断言控件本身；另加一条断言底栏不画范围符号，挡住它被重新加回去。

## 实施状态

**已实施**。`shared/ui/pagination.tsx` 去掉范围行并把页码组改右排，`shared/AppFooter.tsx` 去掉产品名并把右簇改右排，两个词条从两份词表删除，四处用例改写。原型 `_8` 未改动。
