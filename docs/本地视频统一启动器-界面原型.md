# Enjoy 本地视频统一启动器：界面原型

> 本文档依据《本地视频统一启动器-开发基线》整理，使用 ASCII 字符描述首期全部主要页面、弹层与关键状态。界面默认采用深色媒体中心风格，顶部横向导航在各页面保持一致。

## 1. 原型范围与导航

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ Enjoy   [视频库]   [收藏]   [设置]                         [搜索] [刷新] [＋] │
├──────────────────────────────────────────────────────────────────────────────┤
│ 扫描状态：已索引 128 个视频                                                   │
│                                                                              │
│                         主内容区域                                           │
└──────────────────────────────────────────────────────────────────────────────┘
```

通用布局：导航菜单固定在窗口上方横向排列，内容区位于导航下方。顶部导航依次提供 Enjoy 标识、视频库、收藏、设置；右侧提供全局搜索、排序、添加目录和刷新入口。当前页面菜单使用高亮态。

## 7. 系统打开状态

点击播放或双击视频后，将文件交给系统默认播放器打开。调用期间禁用重复操作；调用返回后恢复操作，不显示播放器加载、播放进度或取消播放控件。

调用失败时显示本地化错误及排查编号，支持重试；用户也可使用视频菜单中的“打开所在目录”。成功提交打开请求后更新历史，不监控播放器内部行为。

## 10. 页面状态与交互约定

- 所有页面保留顶部菜单选中态；当前扫描任务在顶部导航的状态区显示百分比。
- 搜索、文件夹筛选、排序和网格/列表视图切换不触发重新扫描。
- 双击视频调用系统默认播放器；调用成功后记录打开次数和时间，不记录播放进度。
- 切换语言即时更新标题、按钮、错误和原生菜单文案；文件名、路径和用户输入的分类名称保持原文。
- 文件被删除或移动时，视频卡片标记为不可用并提供“从索引中移除”。
- 所有错误显示业务错误码对应的本地化文案，不直接展示 Rust、FFmpeg 或系统堆栈。
