# Enjoy 本地视频统一启动器：界面原型

> 本文档依据《本地视频统一启动器-开发基线》整理，使用 ASCII 字符描述已实现的主要页面、弹层与关键状态，供界面走查与验收参照。结构取自实际组件，文案取自实际本地化文案（示例为简体中文）。界面默认采用深色媒体中心风格，顶部横向导航在各页面保持一致。

框内图例：`[ ]` 文字按钮，`[X]` 方形图标按钮，`( )` 下拉选择的当前值，`< >` 文本输入，`{ }` 占位替换，`*` 标记当前所在页。

## 1. 原型范围与导航

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ enjoy   [视频库]*      [收藏]      [最近播放]      [设置]                  │
├────────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│ 主内容区域                                                                 │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
```

导航固定在窗口上方横向排列，内容区位于导航下方。导航依次提供品牌标志与视频库、收藏、最近播放、设置四个入口，当前页以主色高亮并带下边框。导航内没有搜索、刷新或添加目录入口，也不显示扫描状态：搜索与页面操作在各自页面内，扫描进度由进度弹窗承担。

窗口保留系统标题栏和窗口控制按钮，不显示应用原生菜单栏。

尚未选择任何目录时，列表位置显示「尚未选择目录」，「确定」保持禁用。每个已选目录右侧是方形图标移除按钮，无障碍名称为「移除 {路径}」。

卡片依次是缩略图、文件名与一行「时长 + 四个图标按钮」。文件名单行显示，超长省略，悬停用提示展示完整名称。四个图标按钮依次是播放、收藏、打开所在目录、移除索引，均为描边方形按钮，带本地化悬停提示与无障碍名称；收藏按钮在已收藏时填充图标。四个按钮都只在有媒体任务运行时禁用。触发播放且本次打开已提交给系统播放器后，该视频的缩略图左上角出现一枚「上次播放」标签，换播另一个视频时标签随之转移，应用退出后不再保留。

交互：单击卡片任意处打开详情抽屉，文件名本身也是打开详情的入口；右键卡片打开操作菜单，键盘可用菜单键或 Shift+F10 打开。缩略图尚未生成时显示占位。

## 6. 扫描与索引状态

### 6.1 扫描进行中

```text
┌───────────────────────────────────────────────────┐
│ 正在扫描 · 已发现 128 个，已处理 54 个            │
│ 基础信息 128/128 · 元数据 103/128 · 缩略图 54/128 │
│ [###########-------------------] 42%              │
│ /Users/me/Movies/旅行记录.mp4                     │
│                                                   │
│ [暂停]  [取消扫描]                                │
└───────────────────────────────────────────────────┘
```

弹窗标题「正在扫描」仅供读屏使用。进度条随已处理数量增长，右侧是整数百分比；已发现数量为 0 时改为显示加载指示。阶段行按基础信息、元数据、缩略图三段给出就绪数量。暂停后按钮变为「继续」，摘要行中的阶段词变为「扫描已暂停」。

### 6.2 缩略图重建进行中

```text
┌───────────────────────────────────────────────────┐
│ 缩略图重建：找到 128 个，已处理 54 个             │
│ 基础信息 128/128 · 元数据 128/128 · 缩略图 54/128 │
│ [###########-------------------] 42%              │
│ /Users/me/Movies/旅行记录.mp4                     │
│                                                   │
│ [暂停重建]  [取消重建]                            │
└───────────────────────────────────────────────────┘
```

重建缩略图复用同一弹窗，摘要行改为「缩略图重建：找到 {found} 个，已处理 {processed} 个」，按钮为「暂停重建」与「取消重建」。这条分支的摘要模板里没有阶段词，因此暂停与否只由按钮文案体现。

### 6.3 完成通知

```text
┌──────────────────────────────────────────┐
│ 扫描完成                             [X] │
│ 新增 12 个，更新 3 个，移除 1 个。       │
│ [#####################----------]        │
└──────────────────────────────────────────┘
```

浮在右上角，图标与配色由通知类型决定。缩略图重建完成时标题为「缩略图重建完成」。正文给出新增、更新、移除的数量，有媒体处理失败时追加「N 项媒体处理失败。」，有配置目录不可访问时追加「N 个目录当前不可访问。」。两项计数并列，含义不同：前者是媒体解码失败，后者是仍然存在、本次却列不出内容的配置目录，即本次扫描没能覆盖到的范围。整条配置目录已不存在不产生这一项，它按其中的视频都已消失清理。有失败项时通知转常驻，保留到手动关闭；只有目录不可访问时通知仍按 3 秒自动关闭，通知底边上的细线随剩余时间收缩，鼠标悬停或键盘聚焦时暂停。通知关闭后，「有目录没被扫描」在界面上不再有其他地方显示。

## 8. 系统打开状态

点击播放后，将文件交给系统默认播放器打开。调用期间相关按钮禁用；调用返回后恢复，不显示播放器加载、播放进度或取消播放控件。

调用失败时右上角显示本地化错误与排查编号，支持重试；用户也可使用菜单中的「打开所在目录」。成功提交打开请求后计入打开历史，不监控播放器内部行为。

## 10. 通知、确认与加载状态

### 10.1 错误通知

```text
┌──────────────────────────────────────────────────┐
│ 操作失败                                     [X] │
│ 无法访问“/Volumes/Archive”，请检查访问权限。     │
│ 排查编号：err_123                                │
│ [重试]                                           │
└──────────────────────────────────────────────────┘
```

浮在右上角，错误通知不自动关闭，保留到用户处理。正文是业务错误码对应的本地化说明，随后是排查编号行，可恢复时提供「重试」。这里访问不到的可能是一个文件、一个子目录或整条配置目录，文案对三者都成立。多条错误通知在同一容器中依次堆叠，且不会被其他通知顶掉。此处示例只用于说明错误通知的版式：扫描时整条配置目录存在却列不出来不会产生错误通知，该情况只体现在完成通知的「N 个目录当前不可访问。」中。

### 10.2 短提示

```text
┌──────────────┐
│ ✓ 已复制     │
└──────────────┘
```

浮在屏幕顶部水平居中，宽度随内容收缩。用于反馈**结果看不见**的动作，目前只有视频详情的「复制路径」一处：点击已经生效，但界面上没有东西因此改变，没有这块提示这一下就像没点。结果本身看得见的动作不需要它。它与右上角的通知无关：不占用通知位，可与通知同时显示，也不随抽屉关闭而消失。外观是中性色（不借用成功／失败的语义配色），一个实心对勾图标加一句话，没有关闭按钮，也没有随剩余时间收缩的细线——它在 1 秒后自行消失。它刻意不向辅助技术播报：这类提示没有可处置的内容，读屏播报一次「已复制」也不比剪贴板本身多给任何信息。这一秒内点到它不会有任何反应，它也不会把点击放行给被它盖住的东西。

```text
│                 └────────────────┘ │
```

缩略图有三种非图片状态：尚未生成时显示「缩略图待生成」；正在生成时显示加载指示与「正在生成预览」，暂停时显示「预览生成已暂停」；图片加载失败同样回落到「缩略图待生成」。这些占位对读屏提供的名称分别为「{文件名}：缩略图暂不可用」与「{文件名}：正在生成预览」。

## 11. 页面状态与交互约定

- 所有页面保留导航选中态；扫描进度由页面内的进度弹窗呈现；导航不显示扫描状态。
- 搜索、目录筛选与排序只作用于本地已索引数据，不触发重新扫描。排序按页面分别保存：视频库与收藏默认「最近添加」，最近播放默认「最近播放」。
- 单击视频卡片打开详情抽屉，播放由卡片与详情中的独立按钮触发；没有双击播放，也没有网格／列表视图切换。
- 切换语言与主题即时生效；应用不显示原生菜单栏；文件名与路径保持原文。
- 文件被删除或移动时，界面不做任何标记；点播放才显示本地化错误。
- 所有错误显示业务错误码对应的本地化文案，不直接展示 Rust、FFmpeg 或系统堆栈。
- 对话框打开时通知仍显示在最上层且可操作，关闭对话框后回到页面右上角。
