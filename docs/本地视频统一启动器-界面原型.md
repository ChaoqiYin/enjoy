# Enjoy 本地视频统一启动器：界面原型

> 本文档依据《本地视频统一启动器-开发基线》整理，使用 ASCII 字符描述已实现的主要页面、弹层与关键状态，供界面走查与验收参照。结构取自实际组件，文案取自实际本地化文案（示例为简体中文）。界面默认采用深色媒体中心风格，顶部横向导航在各页面保持一致。

框内图例：`[ ]` 文字按钮，`[X]` 方形图标按钮，`( )` 下拉选择的当前值，`< >` 文本输入，`{ }` 占位替换，`*` 标记当前所在页，`●` 共享服务运行中的指示灯。

## 1. 原型范围与导航

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ enjoy  ({空间} ▾)    [视频库]*    [收藏]    [最近播放]    [共享]    [设置] │
├────────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│ 主内容区域                                                                 │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
```

导航固定在窗口上方横向排列，内容区位于导航下方。导航依次提供品牌标志、空间切换器与视频库、收藏、最近播放、共享、设置五个入口，当前页以主色高亮并带下边框。导航内没有搜索、刷新或添加目录入口，也不显示扫描状态：搜索与页面操作在各自页面内，扫描进度由进度弹窗承担。

共享服务运行时，导航里的「共享」右上角亮起一枚指示灯：

```text
     ●  ← 指示灯，服务运行时点亮
[共享]
```

指示灯是 7 像素的圆点，挂在「共享」二字自身的盒上而不是排在导航行里：排在行里会落在文字的垂直中线上，那是句号的位置。它取薄荷绿填充配一圈同族深绿描边——亮色主题下由描边撑起对比度、暗色主题下由填充撑——因此两种主题下都看得见，用的都是主题里现成的那一对绿，没有另造一个颜色。含义写在两处而非颜色里：指针悬停的提示与读屏用的无障碍名称都是「共享服务正在运行」。服务未运行时没有这枚点，入口本身照常在。

空间切换器常驻，即使只有一个空间也显示它的名字；触发按钮与展开的列表取同一个固定宽度，改名与增删都不会让导航宽度变化。触发按钮里的名字按宽度截断，完整名字在列表里读——列表换行而不截断，所以触发按钮上没有悬停提示。展开后列出全部空间，当前那个带对勾图标并标记为当前项；列表只有空间，通往设置页的入口在导航里本来就有。扫描进行中时它不展开，触发按钮只呈现禁用状态：理由以无障碍描述给出，并在设置页「空间」区域可见地写着，不在这个按钮上用悬停提示重复一遍。点击面板外任意处或按 Escape 收起，Escape 同时把焦点还给触发按钮。

窗口保留系统标题栏和窗口控制按钮，不显示应用原生菜单栏。

页面标题右侧是页面操作槽：视频库提供「添加目录」与「扫描」，收藏与最近播放没有操作槽。筛选栏提供搜索框、目录下拉（默认「全部目录」）与排序下拉（最近添加／最近播放／文件名）。

尚未选择任何目录时，列表位置显示「尚未选择目录」，「确定」保持禁用。每个已选目录右侧是方形图标移除按钮，无障碍名称为「移除 {路径}」。

### 3.1 网格视图

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ enjoy  ({空间} ▾)    [视频库]*    [收藏]    [最近播放]    [共享]    [设置] │

│                                                                            │
│ <搜索视频…>      (全部目录)      (最近添加)                                │
│                                                                            │
│ 共 36 个视频                                                               │
│                                                                            │
│ ┌─────────────────────┐ ┌─────────────────────┐ ┌─────────────────────┐    │
│ │ 上次播放  缩略图    │ │ 缩略图              │ │ 缩略图       已共享 │    │
│ ├─────────────────────┤ ├─────────────────────┤ ├─────────────────────┤    │
│ │ 旅行记录.mp4        │ │ 旅行花絮.mkv        │ │ 旅行片段.mp4        │    │
│ │ 01:24:10 播藏夹删   │ │ 00:48:22 播藏夹删   │ │ 00:12:03 播藏夹删   │    │
│ └─────────────────────┘ └─────────────────────┘ └─────────────────────┘    │
└────────────────────────────────────────────────────────────────────────────┘
```

卡片依次是缩略图、文件名与一行「时长 + 四个图标按钮」。文件名单行显示，超长省略，悬停用提示展示完整名称。四个图标按钮依次是播放、收藏、打开所在目录、移除索引，均为描边方形按钮，带本地化悬停提示与无障碍名称；收藏按钮在已收藏时填充图标。四个按钮都只在有媒体任务运行时禁用。触发播放且本次打开已提交给系统播放器后，该视频的缩略图左上角出现一枚「上次播放」标签，换播另一个视频时标签随之转移，应用退出后不再保留。

共享清单里的视频在缩略图右上角另有一枚「已共享」标记：与「上次播放」分处两角（行首是「上次播放」、行尾是共享），一张卡片可以同时戴两枚——一个是本次运行的会话事实，一个是持续到移出清单为止的状态。它取图标而不是文字，因为一整排写着句子的徽标之后，卡片就读不出文件名与时长了；含义写在两处：指针悬停的提示与读屏用的无障碍名称，都是「已共享」。底色取导航指示灯那同一族的薄荷绿——同一件事的两个视角——填充只给 80%，再薄就在最深的缩略图上读不出来了。两枚标记都以绝对定位浮在缩略图角上、不占文档流，卡片高度因此不变。

交互：单击卡片任意处打开详情抽屉，文件名本身也是打开详情的入口；右键卡片打开操作菜单，键盘可用菜单键或 Shift+F10 打开。缩略图尚未生成时显示占位。

## 6. 扫描与索引状态

### 6.1 扫描进行中

```text
┌───────────────────────────────────────────────────┐
│ 正在扫描 · 已发现 128 个，已处理 54 个            │
│ 基础信息 128/128 · 元数据 103/128 · 缩略图 54/128 │
│ [###########-------------------] 42%              │
│ /Users/me/Movies/旅行记录.mp4                     │
│                                                   │
│ [暂停]  [取消扫描]                                │
└───────────────────────────────────────────────────┘
```

弹窗标题「正在扫描」仅供读屏使用。进度条随已处理数量增长，右侧是整数百分比；已发现数量为 0 时改为显示加载指示。阶段行按基础信息、元数据、缩略图三段给出就绪数量。暂停后按钮变为「继续」，摘要行中的阶段词变为「扫描已暂停」。

### 6.2 缩略图重建进行中

```text
┌───────────────────────────────────────────────────┐
│ 缩略图重建：找到 128 个，已处理 54 个             │
│ 基础信息 128/128 · 元数据 128/128 · 缩略图 54/128 │
│ [###########-------------------] 42%              │
│ /Users/me/Movies/旅行记录.mp4                     │
│                                                   │
│ [暂停重建]  [取消重建]                            │
└───────────────────────────────────────────────────┘
```

重建缩略图复用同一弹窗，摘要行改为「缩略图重建：找到 {found} 个，已处理 {processed} 个」，按钮为「暂停重建」与「取消重建」。这条分支的摘要模板里没有阶段词，因此暂停与否只由按钮文案体现。

### 6.3 完成通知

```text
┌──────────────────────────────────────────┐
│ 扫描完成                             [X] │
│ 新增 12 个，更新 3 个，移除 1 个。       │
│ [#####################----------]        │
└──────────────────────────────────────────┘
```

浮在右上角，图标与配色由通知类型决定。缩略图重建完成时标题为「缩略图重建完成」。正文给出新增、更新、移除的数量，有媒体处理失败时追加「N 项媒体处理失败。」，有配置目录不可访问时追加「N 个目录当前不可访问。」。两项计数并列，含义不同：前者是媒体解码失败，后者是仍然存在、本次却列不出内容的配置目录，即本次扫描没能覆盖到的范围。整条配置目录已不存在不产生这一项，它按其中的视频都已消失清理。有失败项时通知转常驻，保留到手动关闭；只有目录不可访问时通知仍按 3 秒自动关闭，通知底边上的细线随剩余时间收缩，鼠标悬停或键盘聚焦时暂停。通知关闭后，「有目录没被扫描」在界面上不再有其他地方显示。

## 7. 视频操作菜单与详情

### 7.1 右键菜单

```text
┌────────────────┐
│ 视频详情       │
│ 播放           │
│ 收藏           │
│ 加入共享清单   │
│ 打开所在目录   │
│ 重新生成缩略图 │
│ 移除索引       │
└────────────────┘
```

菜单在指针位置弹出并自动避开窗口边缘。已收藏时第三项文案为「取消收藏」，已在共享清单里时第四项文案为「移出共享清单」，否则是「加入共享清单」：这两项都排在收藏旁边，因为它们落在同一种标记上、是同一种手势——一项、文案随记录上的标记变，而不是并排两项让人先读完再看自己该点哪个。有媒体任务在跑时除「视频详情」外均禁用。方向键、Home、End 在菜单项之间移动焦点，Escape 或 Tab 关闭并把焦点交还触发它的卡片，点击菜单外或调整窗口大小也关闭。

## 8. 系统打开状态

点击播放后，将文件交给系统默认播放器打开。调用期间相关按钮禁用；调用返回后恢复，不显示播放器加载、播放进度或取消播放控件。

调用失败时右上角显示本地化错误与排查编号，支持重试；用户也可使用菜单中的「打开所在目录」。成功提交打开请求后计入打开历史，不监控播放器内部行为。

```text
│ 最近活动的设备                                                             │
│ 客厅电视      192.168.1.31                                         12 秒前 │
└────────────────────────────────────────────────────────────────────────────┘
```

页面自上而下是标题、服务状态、一个开关按钮、共享清单、连接信息与设备列表。这一页的服务正在运行，所以导航里「共享」的右上角有那枚指示灯——它挂在文字的角上，画不进这一行等宽的框里，形状见第 1 节。

服务状态与开关。状态行是「共享服务正在运行，端口 4918，其他设备可以连接」或「共享服务未运行」；端口写在状态行里，而不只写在下面的地址里，因为端口正是可能出乎意料的那件事——服务要的是 4918，实际落在哪一个空闲端口上要运行起来才知道。开关只有一个按钮：服务要么在跑要么不在，文案说的是这一下把它推向哪边。「开启共享」走主色（开始是这个页面的主操作），「结束共享」走中性色（结束是一次关闭，没有任何东西被撤销或丢弃）。清单为空时按钮禁用，但理由写在清单那一块并给出出路，而不是留给一个灰掉的按钮去解释：一个能让设备连上却什么也找不到的端口，读起来就是一个坏掉的服务。命令在途中时按钮同样禁用，免得一次开或关被按下两次。

共享清单。清单就是带共享标记的那些视频记录本身，读法与每一页读视频的方式相同，后端没有一条专门取清单的命令，所以它不会和列表里显示的东西不一致。卡片与视频库是同一套卡片、同一套右键菜单，「移出共享清单」因此从这里也是一下的事；清单排在连接信息之前，因为它回答的正是上面那个按钮提起的问题——我要分享的到底是什么。清单为空时显示「共享清单是空的，先挑几部要分享的视频」，并给出通往视频库的链接「去视频库挑选」。清单与服务正在提供的那一份不一致时，只有在服务运行中才出现的两行警告会说清楚：「清单改过了：正在共享的这一份还是开启时的那份，重启服务才会生效」，以及清单里有文件已不在磁盘上时的「共享清单里有 N 个文件已不在磁盘上，电视上看不到它们」。两行都只在服务运行中说，「和一份不存在的清单不一致」不是关于任何东西的事实。

连接信息。这一块不论服务是否运行都显示，这正是它的用处：密码是在界面第一次问到它时生成的，因此可以在什么都还没应答之前就抄下来、填进电视，这一块也永远不会是一个只有标题的空壳。服务未运行时写「共享服务未运行。开启之后，这里会列出可以填进电视的地址」；运行时写「在电视上新建一个 WebDAV 源，把下面的地址和账号密码填进去即可」。地址一行一条，取本机地址加服务实际占用的端口，结尾带斜杠——那是协议自己表示「这是一个可以浏览的集合而不是一个文件」的方式；每条各有一个「复制地址」，无障碍名称带上该行的地址，读屏与测试因此分得清是哪一行的复制。回环地址排在最后并标出「仅本机可用」，因为它是最容易被误试的那一条。网卡全都没有地址时，这一块写「共享服务正在运行，但这台电脑现在没有可用的网络地址。请检查网络连接」，而不是留一张空表。用户名固定是 enjoy，不可改。

密码默认显示四个圆点：每一位密码都是四位数字，遮罩并不比屏幕晚一步多说任何东西，而一个与要在遥控器上按的长度不一致的遮罩只会更糟——它让页面可以在房间里晾着，也可以被拍照。三个操作：显示密码／隐藏密码（按下即显示，不跨访问保留，按钮带按下态）、复制密码（复制的是密码本身而不是屏幕上那串圆点，这个按钮正是为没要求看见它的人准备的）、重新生成密码。运行中的服务仍在核对旧密码时，右侧显示「重启共享服务后新密码才生效」——只在它为真的时候说。

设备列表。只在服务运行时出现：没有人是一个不存在的服务的客户端，而一个停掉的服务下面挂一张空列表，读起来像在抱怨一件没被要求的事。口径写在页面上，而不是留给悬停提示：「这里列出最近一分钟内请求过视频的设备。WebDAV 客户端是取完自己要的东西就断开的，所以这里显示的是「刚刚来过」，不是「正在播放」——设备安静一分钟以上才会从列表里消失」。等着某一行随影片结束而消失的人，会把这一页当成坏的。没说过自己是谁的客户端照样有一行，名字显示「未知」，因为地址与时刻才是这一行真正的构成；时间显示为「N 秒前」，按一个自己走的时钟数，两个时钟哪怕只差一丝也不会显示成「0 秒前」。一行都没有时写「最近一分钟内没有设备请求过」。

服务结束时的确认。服务运行时，切换空间与关闭窗口都会先问一次，两处问的是同一件事——结束服务会切断设备可能正在读取的连接——因此共用同一个模态对话框，见 11.7 与 11.8。在本页按下「结束共享」则不再问一遍：用户就在这一页上、刚点的就是它，再问一次只是把同一句话重复给已经听懂的人。

显示语言提供跟随系统、简体中文、English；主题提供跟随系统、亮色、暗色。两者都即时生效并写入本地设置；语言保存失败时在通知区显示本地化错误并保留重试，当前界面语言不变。

「空间」区域是一列紧凑的行，整体一个带边框、行间有分隔的块，与下面「视频目录」那些一行一个路径的卡片刻意不同形：每行是名字、当前标记与重命名、删除两个方形图标按钮（无障碍名称分别是「重命名空间」「删除空间」），区域底部是「新建空间」。新建与重命名共用一个对话框，字段为「空间名称」，名字去空格后不能为空、最长 24 个字符、也不能与已有空间重名；被拒的名字报在字段旁并保留已输入的内容。删除在其上方弹出确认气泡，内容为「删除空间“{名称}”？该空间的收藏与播放记录会被清空，磁盘上的视频文件不会被删除。」，提供「确定」与「取消」。最后一个空间照样提供删除，后端拒绝并说明至少要留一个空间，被拒的删除走通知区——它没有一处是「本地于这一行」的，因此不像被拒的名字那样报在字段旁。扫描进行中时区域顶部给出理由，三个操作一并禁用。

「视频目录」区域的标题带上当前空间的名字，因为同一台机器上不同空间配的是不同的目录。

目录行右侧是方形图标移除按钮（无障碍名称「移除目录」），点击后在其上方弹出确认气泡，内容为「移除“{路径}”的索引？」，提供「确定」与「取消」，点击别处或按 Escape 关闭。该确认不是模态弹窗。

「更新」区域显示当前版本并提供「检查更新」。检查只由这个按钮触发，应用启动时不检查，按钮因此始终显示——它是在这个区域内发起检查的唯一途径，检查结果不通过移除它来表达。结果是「已是最新版本」或平台不发布自动更新时，以浮动通知告知，不写进区域文字。手动检查失败会在通知区显示本地化错误与重试。检查到新版本后，区域显示版本号与「下载」，并在下方就地显示发布日期与更新内容，让用户在下载前就能读到这次改了什么；下载进度就地以进度条展示；下载并校验完成后改为提示重启并提供「立即重启」。安装交由系统安装器完成，应用会在安装开始时退出。

## 11. 通知、确认与加载状态

### 11.1 错误通知

```text
┌──────────────────────────────────────────────────┐
│ 操作失败                                     [X] │
│ 无法访问“/Volumes/Archive”，请检查访问权限。     │
│ 排查编号：err_123                                │
│ [重试]                                           │
└──────────────────────────────────────────────────┘
```

浮在右上角，错误通知不自动关闭，保留到用户处理。正文是业务错误码对应的本地化说明，随后是排查编号行，可恢复时提供「重试」。这里访问不到的可能是一个文件、一个子目录或整条配置目录，文案对三者都成立。多条错误通知在同一容器中依次堆叠，且不会被其他通知顶掉。此处示例只用于说明错误通知的版式：扫描时整条配置目录存在却列不出来不会产生错误通知，该情况只体现在完成通知的「N 个目录当前不可访问。」中。排查编号指向的内容写在应用数据目录的 `enjoy.log` 里，与视频库数据库 `enjoy.db` 同处一地；界面只给出编号，日志本身不进入界面。界面自己产生的失败用同一个通知形状与同一行编号，只是它没有后端调用可查。

### 11.2 短提示

```text
┌──────────────┐
│ ✓ 已复制     │
└──────────────┘
```

浮在屏幕顶部水平居中，宽度随内容收缩。用于反馈**结果看不见**的动作，目前只有视频详情的「复制路径」一处：点击已经生效，但界面上没有东西因此改变，没有这块提示这一下就像没点。结果本身看得见的动作不需要它。它与右上角的通知无关：不占用通知位，可与通知同时显示，也不随抽屉关闭而消失。外观是中性色（不借用成功／失败的语义配色），一个实心对勾图标加一句话，没有关闭按钮，也没有随剩余时间收缩的细线——它在 1 秒后自行消失。它刻意不向辅助技术播报：这类提示没有可处置的内容，读屏播报一次「已复制」也不比剪贴板本身多给任何信息。这一秒内点到它不会有任何反应，它也不会把点击放行给被它盖住的东西。

被移除的记录若也带着共享清单的标记，这份确认会多一行「它也在共享清单里，移除后清单上就没有它了」：记录被删掉，标记随之消失，正在服务的电视也就看不到它了，这正是「电视上怎么突然没有了」的答案。只在它为真的时候说——每次移除都挂一条警告，用户就学会一眼跳过它。

### 11.8 共享运行中退出应用确认

```text
┌────────────────────────────────────────────────┐
│ 共享服务正在运行：现在退出会结束它，           │
│ 正在传输的文件会中断                           │
│                                                │
│                                 [取消]  [退出] │
└────────────────────────────────────────────────┘
```

这两个确认问的是同一件事：结束共享服务会切断设备可能正在读取的连接，而离开服务所属的空间与关闭窗口都会结束它。两者都不是被禁止的操作——用户很可能就是要这样——所以这里问一句而不是拒绝。它们与「移除索引确认」是同一个模态对话框：「答案只有两个按钮可达」的那一层由模态本身承担，Escape 等同于「什么都不做」的那一个答案，也就是「取消」。切换空间时，只有服务真的停了才真的切过去——否则会留下一个服务在后头服务着已经不在屏幕上的那个空间；服务停不下来由右上角的错误通知报出，确认框已经先收起来，免得一块模态挡着用户要读的那条失败。退出确认由后端应答：结束服务与关闭窗口是同一条命令，因为它们是同一个答案；这一次调用要是失败，能看到失败的那个窗口正是正在关闭的那一个，所以确认框无论如何都收起来。

## 12. 页面状态与交互约定

- 所有页面保留导航选中态；扫描进度由页面内的进度弹窗呈现；导航不显示扫描状态。
- 搜索、目录筛选与排序只作用于本地已索引数据，不触发重新扫描。排序按页面分别保存：视频库与收藏默认「最近添加」，最近播放默认「最近播放」。
- 单击视频卡片打开详情抽屉，播放由卡片与详情中的独立按钮触发；没有双击播放，也没有网格／列表视图切换。
- 切换语言与主题即时生效；应用不显示原生菜单栏；文件名与路径保持原文。
- 文件被删除或移动时，界面不做任何标记；点播放才显示本地化错误。
- 所有错误显示业务错误码对应的本地化文案，不直接展示 Rust、FFmpeg 或系统堆栈。
- 对话框打开时通知仍显示在最上层且可操作，关闭对话框后回到页面右上角。
- 共享服务属于开启它的那个空间：切换空间或关闭窗口都会先问一次（见 11.7 与 11.8），确认之后服务才结束。服务运行时导航里的「共享」右上角亮着指示灯，任何页面都看得见。
- 渲染期间抛出的异常不会留下一个空白窗口：整屏换成本身的基础底色，并在右上角显示常驻错误通知「界面绘制失败，请重试」（版式见 11.1），这条通知的关闭就是重新绘制一次。它接的只有渲染期异常，事件回调、定时器与未处理的拒绝不从这里经过，那些在抛出处置。
