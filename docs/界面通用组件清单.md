# 界面通用组件清单

本文档是界面由 daisyUI 迁至 shadcn/ui 的组件契约：通用组件有哪些、各自出现在哪些界面、接受什么参数。
原型依据 `prototype-drawing/_1` 至 `_9`（均为 Crimson Cinema 暗色稿）与两份 `DESIGN.md`。

## 1. 这次改什么、不改什么

**改**：表现层。组件实现、类名、设计 token 的载体。

**不改**：领域行为（扫描、共享服务、空间切换）、i18n 体系与文案、`shared/api.ts` 作为后端唯一地址的分工，以及 7 个窄接口（`useVideos` / `useScan` / `useNotices` / `useSpaceCommands` / `useDirectories` / `useVideoActions` / `useBusy`）的职责划分。

**迁移后必须改写的既有约定**（详见 §7）：`docs/开发指南.md` 第 46 条（daisyUI 优先）、按钮规范、下拉选择框一节、原来的「虚拟渲染与测量」整节，`docs/本地视频统一启动器-开发基线.md` §6，以及 `docs/本地视频统一启动器-界面原型.md` 的导航指示灯与页面状态约定。**这些已在 #73 收口时改写完毕**。`frontend/src/style.css` 中三处 daisyUI 内部选择器覆写也已移除（`check-tokens.mjs` 断言 `@plugin`、`--page-scroll-lock`、`drawer-side`、`--video-card-shadow` 都不在）。

## 2. 设计 token

shadcn 语义变量是唯一真源；`dark:` 自定义变体**继续绑定 `[data-theme='dark']`**，不改 `ThemeSetting` 与两个 HTML 入口。

### 2.1 有对应槽位的

| 原型 token | shadcn 变量 | 备注 |
|---|---|---|
| `surface-canvas` / `background` | `--background` | 页面底色 |
| `surface-card` | `--card` | 卡片 |
| `surface-elevated` | `--accent` | 悬停与抬升面 |
| `surface-container-low` / `-high` / `-highest` | `--muted` / `--secondary` / `--accent` | 三档归两槽，按深浅就近 |
| `text-primary` / `on-surface` | `--foreground` | |
| `text-muted` / `on-surface-variant` | `--muted-foreground` | |
| `primary` / `primary-container` / `on-primary` | `--primary` / `--primary-foreground` | |
| `toast-neutral` | `--popover` | Toast 与浮层底 |
| `error` / `error-container` / `on-error` | `--destructive` / `--destructive-foreground` | |
| `outline` / `outline-variant` / `border-subtle` | `--border` / `--input` | |
| 聚焦环 | `--ring` | 见 §7，需统一色相 |

### 2.2 需要扩展的槽位

shadcn 默认没有 success / warning / info 三槽，而现有语义色与原型都在用：

| 新增变量 | 来源 | 用在哪 |
|---|---|---|
| `--success` / `--success-foreground` | 原型 `mint-running` + `mint-stroke-deep` | 共享指示灯、已索引、硬解就绪、播放主按钮 |
| `--warning` / `--warning-foreground` | 原型 `amber-gold` | 收藏星标、路径图标、警告文案 |
| `--info` / `--info-foreground` | 现有 `btn-info`（目录访问、清除筛选） | 次要信息类操作 |

原型里这三组色在 Crimson 主题下被硬改成赤红（`mint-running` → 红），属于原型未收敛，**本次以语义为准**：`--success` 保持绿、`--warning` 保持琥珀金。

### 2.3 业务 token（原型特有，保留）

| 变量 | 用途 |
|---|---|
| `--glow` | 强调元素的发光阴影色（红晕），取代散落的 `shadow-[0_0_16px_rgba(255,51,75,…)]` |
| `--share` / `--share-border` | 「已共享」角标（原型 `status-shared` / `status-shared-border`） |
| `--last-played` | 「上次播放」标记（原型 `last-played`） |

### 2.4 字体与图标

- **字族**：两份 `DESIGN.md` 都写全族 Space Grotesk，原型的 Manrope 是稿子用的 CDN 字体，不采纳。
- **等宽**：原型里 `font-mono-data` 用得极重（路径、时长、端口、快捷键）。用系统等宽栈 `ui-monospace, SFMono-Regular, Menlo, monospace`，**不引入 JetBrains Mono**。
- **图标**：**继续用 `lucide-react`**（已在依赖里），不引入原型的 Material Symbols。原型里的 `movie_edit` / `folder_open` 等一一对应到 lucide 图标。页头五个导航项也各带一枚前置图标（`app/MainNav.tsx`，14 像素、装饰性），其中「收藏」与「共享」复用视频卡片上那两枚同义图标；选取、排除与宽度代价见 [ADR 0024](adr/0024-页头导航项加前置图标.md)。
- **基准字号**：保留 `html { font-size: 14px }`（`style.css:5-7`）。

### 2.5 侧栏槽位（全部映射到既有 token）

设置页左列是一块有自己底色的面板。它借用一组 shadcn 侧栏的槽位名，但**每一个都指向既有语义 token**，没有引入任何新的颜色：

| 新增变量 | 指向 | 用在哪 |
|---|---|---|
| `--sidebar` | `--card` | 面板底色（原型 `_5` 的 `bg-surface-card`） |
| `--sidebar-foreground` | `--card-foreground` | 面板上的文字 |
| `--sidebar-accent` | `--secondary` | 行的悬停与当前项（与主题分段条的选中块、`ToggleGroup` 的选中段同色） |
| `--sidebar-accent-foreground` | `--secondary-foreground` | 上面那层的文字 |
| `--sidebar-border` | `--border` | 面板边框与子菜单的竖线 |
| `--sidebar-ring` | `--ring` | 行的聚焦环 |

只写在 `:root` 一份（值是 `var()`），跟随明暗由「自定义属性在使用点求值」承担，`[data-theme='dark']` 块零改动。实测两套主题下它与页面底色的通道差是 (2,4,2) 与 (3,4,6)——**划出边界的主要是 `--sidebar-border` 那一圈**，不是底色。缘由见 [ADR 0023](adr/0023-设置页改用-shadcn-的-sidebar-与-rubber-segment.md)。

「被选中/当前的那一块」全仓统一取 `--secondary`（`surface-container-high`），不取 `--accent`（`surface-elevated`）：`--accent` 在亮色下是一块面（`#ffe4e6` 对近白），在暗色下只是一层悬停水洗（`#1a1e26` 只比 `#111317` 的页面高 9~15 级）。三处落点——设置页的主题分段条、设置页左列的当前行、工具栏的视图模式——用同一块填色。见 ADR 0023 §五。

## 6. 三条必须保住的既有契约

**`Drawer`（ADR 0006 / 0007）**：外壳常驻挂载、关闭时不卸载；`open` 只翻转状态（迁移后翻的是外壳的 `inert`）；唯一位移来源是一套过渡——迁移前是 daisyUI 的 `translate` 属性过渡，迁移后是 Radix `Sheet` 的 `animate-in`/`animate-out` `transform` 关键帧（`slide-in-from-right`）；这条性质的理由不变且仍然成立：ADR 0007 记的「滑过头再闪回」正是两个位移源叠加的反例，换库时不能重蹈；`inert={!open}`；焦点在关闭**开始时**归还（Radix 自己的归还目标是触发器，而这里的抽屉由状态开启，故仍由 `Drawer` 自己归还）；面板上限 `max-w-[440px]`。**实现状态（迁移后，非契约性质）**：`--page-scroll-lock` 那条治 macOS 标题栏变灰的补丁已随 daisyUI 删除，滚动锁改由 Radix 承担；焦点陷阱原为已知缺口，**已由 Radix 补上**，#72 与 #74 用真实键盘 Tab 实测过一圈回绕，属行为变化。

**`Toast`（`开发指南.md:68-83`）**：类型词表只有 4 种；配色类必须是完整字面量，**禁止模板拼接**（`alert-${type}` 不生成样式）；`error` 用 `role="alert"`、其余 `role="status"`；倒计时细线用 `bg-current` 而非进度条组件；非错误通知全局只留最新一条。

**`ScrollViewport`（`开发指南.md:272-280`）**：`scrollbar-gutter: stable` 设在真正的滚动元素上，补偿 `max(0px, 20px - 原生槽宽)`。Radix `ScrollArea` 会自绘滚动条，与这条冲突，**因此不采用**。

## 8. 已定事项与已知限制

原先的「待裁决」全部已定，落点在代码里可核：

1. **后端分页**：已落地（#58）。`list_videos` 收 `VideoQuery`、返回 `VideoPage`；筛选含文件名搜索、目录、`favorite` / `shared` / 有播放历史；排序含最近添加、最近播放（升/降两向合并为一项、由方向参数表达）、文件名、文件体积。原先担心的 `shared/api.ts` 行数问题已按约定解决：类型声明拆到 `shared/apiTypes.ts`，`invoke` 仍留在 `api.ts`，`check-seam.mjs` 已登记 `VideoQuery` / `VideoPage`。
2. **圆角基准**：定 `.5rem` 且亮暗共用（`style.css` 的 `--radius`），`check-tokens.mjs` 断言只有一处取值。视频卡片取其中 `rounded-md` 那一档，也就是主色按钮的圆角（`calc(var(--radius) - 2px)`；`@theme inline` 把主题值解析进工具类，运行时没有 `--radius-md` 可指，所以写它内联前的表达式），工具栏、设置卡、对话框等 12px 表面与列表行那档 8px 都不动。
3. **表格视图的列**：八列——文件名 / 时长 / 分辨率 / 编码 / 大小 / 修改时间 / 路径 / 操作（`features/library/VideoTable.tsx`）。**「格式」列不设**——`Video` 没有容器格式字段。
4. **列表视图形态**：单列紧凑行，缩略图在左、文件名与元信息在中、`VideoActions` 在右（`features/library/VideoRow.tsx`）。
5. **聚焦环色相**：统一取主色（`--ring`），`check-tokens.mjs` 断言聚焦环等于主题主色。
6. **每页条数**：24，不做条数选择器（`features/library/listing.ts` 的 `PAGE_SIZE`）。
7. **视图模式的记忆**：与排序同规，按页面分别保存，四个列表页默认「网格」（`features/library/libraryView.ts` 的 `viewModes` 与 `DEFAULT_VIEW_MODE`）。
