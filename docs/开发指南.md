# 开发指南

本指南适用于所有贡献者和自动化代理。具体产品功能与软件设计参见[本地视频统一启动器开发基线](本地视频统一启动器-开发基线.md)，此处统一维护开发约束。

本指南按主题拆成六份，都在 `docs/guides/` 下。**改仓库之前先读「编码与架构」**——编码风格、导入规则、路径与行数限制、架构原则都在那里，对每一处改动都成立；其余的按手头的事读对应的一份，不必把六份都读完。

| 读哪一份 | 收的是哪几节 | 什么时候读 |
|---|---|---|
| [编码与架构](guides/编码与架构.md) | 编码风格与命名、导入规则、跨平台文件路径、文件行数限制、架构与设计模式、提交与合并请求 | 每次改动之前 |
| [界面约定](guides/界面约定.md) | 按钮样式、提示、通知、短提示、下拉选择框、路由与页面组合 | 改按钮、提示、通知、选择框或页面装配 |
| [列表与滚动](guides/列表与滚动.md) | 视频列表布局与渲染、滚动条占位与兼容处理、滚动功能验证 | 改四个列表页的布局、渲染或滚动 |
| [测试与检查](guides/测试与检查.md) | 测试与检查、当前后端验证命令、自动检查、独立网页验收 | 写测试、跑检查、用网页验收 |
| [开发与启动](guides/开发与启动.md) | 开发环境与命令、VS Code 启动、前端工具链、窗口何时出现、日志与故障排查 | 搭环境、起应用、查日志、排启动问题 |
| [构建与发布](guides/构建与发布.md) | 发布、标志与应用图标 | 发版、换图标 |
