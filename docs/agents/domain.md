# Domain docs

## 布局与阅读规则

本仓库采用 single-context：

- 根目录 `CONTEXT.md`：领域术语与概念。
- `docs/本地视频统一启动器-cordis重写-第一版.md`：产品范围、架构与实现决策。
- `app/README.md`：运行、测试与打包。

探索代码前阅读 `CONTEXT.md`，并阅读重写方案中与当前任务相关的章节。
文件尚不存在时直接继续；由 domain-modeling 在术语或决策明确后按需创建。

## 术语与决策

Issue、设计建议、诊断假设和测试名称使用 CONTEXT.md 定义的术语。
发现术语缺口时，记录给 domain-modeling 后续完善。

重写方案的决策与实现冲突时，明确指出相关章节、冲突内容及重新讨论的理由。
