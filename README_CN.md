# Enjoy

[English](README.md) / 简体中文

[![项目检查](https://github.com/ChaoqiYin/enjoy/actions/workflows/check.yml/badge.svg?branch=main)](https://github.com/ChaoqiYin/enjoy/actions/workflows/check.yml)

**把散落在不同文件夹里的本地视频，整理成一个随时可打开的视频库。**

Enjoy 是基于 Tauri、React 和 Rust 构建的本地视频库桌面客户端。添加目录后，即可浏览视频封面、搜索文件、收藏内容，并通过系统默认播放器开始播放。

视频索引和缩略图保存在本机，无需部署独立服务。

[快速开始](#快速开始) · [使用说明](#使用说明) · [文档与支持](#文档与支持) · [参与贡献](#参与贡献)

## 功能

- **多空间**：维护多个相互独立的视频库，各自拥有视频目录、视频记录、收藏与最近播放，可随时切换；同一时刻只展示一个空间。
- **统一视频库**：在**当前空间内**添加多个目录，递归扫描 MP4、MKV、AVI、MOV、WEBM、M4V、MPG、MPEG、WMV 等常见视频文件。
- **封面与详情**：自动生成缩略图，读取时长、分辨率和编码等信息。
- **快速查找**：按文件名搜索、按目录筛选，结合排序、收藏和最近播放找到视频。
- **直接播放**：点击播放按钮，使用系统默认播放器打开视频；也可打开文件所在目录。
- **保持库同步**：文件新增、移走或删除后手动重新扫描，也可重建缩略图；处理任务支持暂停、继续和取消。
- **共享给其他设备**：把要分享的视频加入共享清单，开启内置的只读 WebDAV 服务，局域网上的电视、平板或手机即可浏览和播放。
- **流畅浏览**：响应式卡片网格配合虚拟滚动，仅渲染可见区域附近的内容。
- **界面偏好**：支持简体中文、英文及跟随系统语言，提供浅色、深色和跟随系统主题。
- **应用更新（仅 Windows）**：在设置页检查新版本并就地下载；下载支持暂停、继续和取消，重启后完成安装。

## 快速开始

当前提供源码运行、本地打包，以及从[发布页](https://github.com/ChaoqiYin/enjoy/releases)安装已发布的 Windows 版本。已有 macOS 构建与运行验证；Windows 和 Linux 的完整验收尚未完成。

### 准备环境

| 依赖            | 要求与用途                                                                     |
| --------------- | ------------------------------------------------------------------------------ |
| Node.js         | 22 LTS，运行前端工具链                                                         |
| npm             | 11，安装依赖并执行项目命令                                                     |
| Rust            | stable，编译桌面后端                                                           |
| 系统构建工具    | 按 [Tauri 环境准备](https://v2.tauri.app/start/prerequisites/)安装对应平台依赖 |
| FFmpeg、FFprobe | Windows 安装包已内置；其他情况需在应用进程的 `PATH` 中可用                   |
| 视频播放器      | 安装可打开相应视频格式的播放器，并设置系统文件关联                             |
| WebDAV 客户端   | 仅共享功能需要：安装在接收共享的设备上（多数电视已内置）                       |

Windows 安装包已内置 FFmpeg 和 FFprobe，无需另行安装。其他平台以及从源码运行时需要自行安装，可通过 [FFmpeg 下载页面](https://ffmpeg.org/download.html)获取适合平台的安装方式，并在终端确认：

```sh
ffmpeg -version
ffprobe -version
```

### 启动桌面应用

```sh
git clone https://github.com/ChaoqiYin/enjoy.git
cd enjoy
npm ci
npm run desktop
```

首次启动会编译 Rust 后端，耗时取决于本机环境。开发模式会自动启动或复用本项目的 Vite 服务，然后打开桌面窗口。

### 本地打包

在仓库根目录执行：

```sh
npm exec tauri build
```

构建产物位于 `src-tauri/target/release/bundle/`。打包后的界面随应用内置，运行时无需启动 Vite。

Windows 发布构建需要 `resources/ffmpeg/windows-x86_64/` 中的 `ffmpeg.exe`、`ffprobe.exe` 和 `LICENSE.txt`，缺少时构建失败。`LICENSE.txt` 随仓库保存，两个可执行文件不入库，由发布流程从仓库的 `ffmpeg-tools` 发布附件取回。本地打包需先按[媒体工具说明](resources/ffmpeg/windows-x86_64/README.md)放入配套工具。Windows 安装包会内置这三项，安装后不依赖 `PATH`。

## 使用说明

1. Enjoy 打开时处在一个**空间**里。在设置页新建、重命名或删除空间，通过导航栏的切换器在空间之间切换。每个空间各自拥有视频目录、视频记录、收藏与最近播放。
2. 打开视频库，点击 **添加目录**，为当前空间选择一个或多个视频目录并开始扫描。
3. 基础索引建立后即可浏览卡片，元数据和缩略图会随处理进度补齐。
4. 使用搜索、目录筛选和排序查找视频，也可收藏常看的内容。
5. 点击播放图标，通过系统默认播放器打开视频。
6. 在设置页管理空间和视频目录、重建缩略图，以及调整语言和主题。Windows 上还可以在设置页检查并下载应用更新。

### 共享给其他设备

共享会把挑中的视频作为只读的 WebDAV 媒体库提供给局域网。

1. 在视频库、收藏或最近播放页的右键菜单里把视频加入共享清单。
2. 打开导航栏的**共享**页，点击 **开启共享**。
3. 在另一台设备上新建 WebDAV 源，填入页面上列出的地址、用户名 `enjoy` 和四位数字密码。

- 服务是只读的：客户端可以浏览和播放清单里的视频，但无法通过它改名、删除或替换磁盘上的任何文件。
- 只提供当前空间的共享清单。切换空间或退出应用都会结束服务，服务运行中会先要求确认。
- **最近活动的设备**列出最近一分钟内请求过视频的客户端。WebDAV 客户端取完自己要的东西就会断开，所以这里显示的是「刚刚来过」，不是「正在播放」。
- 服务运行期间改动共享清单不会改变它正在提供的那一份，重启服务才会生效。
- 密码是四位数字，以明文 HTTP Basic 认证发送。它挡的是没有被告诉过这台服务的设备，挡不住会去试的设备，也挡不住能看到局域网流量的人。

### 文件与播放记录

- 从视频库移除索引不会删除原始视频文件。若该视频在共享清单里，移除索引会同时把它移出清单。
- 删除空间会清空它的视频目录、视频记录、收藏与播放历史；磁盘上的视频文件不受影响。
- 文件被移走或所在目录暂时不可访问时，界面不做标记，点播放才显示本地化错误。
- 最近播放记录的是成功发起系统打开操作的时间和次数，不代表已观看，也不记录播放器内的播放进度。
- 视频详情可查看卡片之外的元数据；错误以浮动通知显示，并在支持时提供重试入口。

## 开发

前端使用 React、TypeScript、Tailwind CSS 和 daisyUI；桌面能力由 Tauri 2 与 Rust 提供，SQLite 保存视频索引，FFmpeg 和 FFprobe 负责媒体处理，内置的只读 WebDAV 服务负责局域网共享。

| 目录              | 职责                                         |
| ----------------- | -------------------------------------------- |
| `frontend/`       | 页面、组件、前端配置、静态资源及网页验收入口 |
| `src-tauri/`      | Rust 后端、系统接口、窗口权限与打包配置      |
| `shared/locales/` | 前后端共享的中英文翻译                       |
| `assets/brand/`   | 品牌素材与应用图标源图                       |
| `scripts/`        | 仓库检查、开发服务及资源生成工具             |
| `docs/`           | 设计、开发指南与验收记录                     |

所有命令均在仓库根目录执行：

| 命令                                              | 用途                       |
| ------------------------------------------------- | -------------------------- |
| `npm run desktop`                                 | 启动桌面开发环境           |
| `npm run dev`                                     | 启动前端开发服务           |
| `npm run check`                                   | 检查源码规范、翻译和格式   |
| `npm test`                                        | 运行前端测试               |
| `npm run build`                                   | 检查 TypeScript 并构建前端 |
| `cargo test --manifest-path src-tauri/Cargo.toml` | 运行后端测试               |

仅验收网页布局时，执行 `npm run dev` 后访问 [网页验收入口](http://127.0.0.1:5173/acceptance/web-acceptance.html)。该入口使用模拟数据，不连接真实视频库；播放操作会固定返回错误，用于检查通知和重试交互。完整本地功能请通过桌面应用使用。

更多格式化、静态检查、媒体集成测试及打包命令见[开发指南](docs/开发指南.md)。
