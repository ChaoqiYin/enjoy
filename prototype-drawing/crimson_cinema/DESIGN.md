# Crimson Cinema Design System

深色媒体中心高能科技主题。将原先的冷青色与薄荷绿升级为充满热情、活力与视觉冲击力的赤红（Crimson Red / Vermilion）与深绯光晕体系。
- 主强调色：`#ff334b`，用于主要按钮、激活态下划线、状态焦点
- 共享指示灯与胶囊：`#ff4d6d` 搭配深红边框 `#991b32`
- 界面质感：曜石黑暗黑底色、微光边缘拟态、赤红脉冲与高对比白文字
