# Vermilion Studio Design System

极简明亮工作室热情主题。将原先冷冽的青蓝色升级为富有感染力、饱满热情的朱绯红（Rose Vermilion）。
- 主强调色：`#e11d48`（Rose 600），高饱和度且在浅色底上对比清晰
- 浅底交互：淡绯色背景 `#fff1f2`，柔和边框 `#e2e8f0`
- 状态指示灯与已共享胶囊：朱绯红搭配深红描边，保持绝佳的无障碍可读性
